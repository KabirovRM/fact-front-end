## 2. Локальная сборка и пуш

### 2.1. Запустить сборку

```bash
cd /home/kabirovrm/fact-frontend
set -a && source .env && set +a
./scripts/build.sh
```

### 2.2. С параметрами

```bash
# Свой тег
IMAGE_TAG=staging ./scripts/build.sh
```

### 2.3. Что делает скрипт

1. Создаёт `.npmrc` с авторизацией для `repo.fact.digital`
2. Логинится в `registry.gitlab.com`
3. Собирает образ из `node:22-alpine` + `nginx-unprivileged`
4. Пушит в `registry.gitlab.com/kabirovrm/fact-front-end/fact-frontend`

### 2.4. Результат

Образ доступен по пути:
```
registry.gitlab.com/kabirovrm/fact-front-end/fact-frontend:develop
```

Скачать:
```bash
docker pull registry.gitlab.com/kabirovrm/fact-front-end/fact-frontend:develop
```

## 3. Структура образа

### Dockerfile

```dockerfile
# Build stage
FROM node:22-alpine as build
WORKDIR /app
COPY .npmrc .npmrc
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build && rm -rf .npmrc

# Final stage
FROM nginxinc/nginx-unprivileged:stable-alpine as final
COPY --from=build /app/dist /usr/share/nginx/html
COPY nginx/default.conf.template /etc/nginx/templates/default.conf.template
EXPOSE 8080
```

### nginx/default.conf.template

```nginx
server {
    listen 8080;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # SPA routing
    location / {
        try_files $uri $uri/ /index.html;
    }

    # API proxy
    location /api/ {
        proxy_pass http://localhost:8080/api/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # WebSocket
    location /app/${PUSHER_APP_KEY:-67890}/ws {
        proxy_pass http://localhost:6001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_read_timeout 86400;
    }

    # Кэширование
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### Что запускается внутри

| Процесс | Порт | Описание |
|---|---|---|
| Nginx | 8080 | Статический фронтенд |
| SPA routing | — | Все роуты отдают index.html |
| API proxy | — | Проксирование /api/ на бэкенд |
| WebSocket | — | Подключение к Soketi |

## 7. Возможные проблемы

| Проблема | Решение |
|---|---|
| Login в GitLab Registry не прошёл | Проверить `GITLAB_REGISTRY_USER` / `GITLAB_REGISTRY_PASSWORD` |
| `unauthorized to access repository` | Убедиться, что токен имеет scope `write_repository` |
| `npm install` падает (E401) | Проверить `NPM_REGISTRY_USER` / `NPM_REGISTRY_PASSWORD` |
| `npm run build` падает | Проверить зависимости в `package.json` |
| Статические файлы не отдаются | Проверить nginx конфигурацию |
| API запросы не проксируются | Проверить, что бэкенд запущен на порту 8080 |
